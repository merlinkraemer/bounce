# Contributing

Issues and pull requests are welcome. Bounce is maintained in spare time, so there is no promise of response time.

- Open an issue before a large change.
- Keep pull requests small and focused on one thing.
- No third-party dependencies.
- Follow the Swift conventions in [AGENTS.md](AGENTS.md).
- Run `swift test` in `apps/BounceKit` and make sure both apps build before sending a PR.
- Use the dev lane for testing (see [BUILDING.md](BUILDING.md)). Do not change bundle IDs, Bonjour services or keychain services without discussing it first.
- Report security problems privately, see [SECURITY.md](SECURITY.md).

By contributing you agree that your work is released under the [MIT license](LICENSE).
